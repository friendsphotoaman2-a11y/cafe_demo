# Smart Table Ordering & Billing System (Cafe POS)

A production-ready, full-stack Smart Table Ordering, Kitchen Display (KDS), and Counter Billing system tailored for cafes in India.

## Tech Stack
- **Frontend & Server**: Next.js 15 (App Router, TypeScript, Tailwind CSS v4, Lucide Icons)
- **Database & Auth**: Supabase (PostgreSQL, Row Level Security, Realtime, RPC Stored Procedures)
- **Google Sheets API**: Service Account integration via `googleapis` (`Orders`, `OrderItems`, `Customers` tabs)
- **Receipts & Invoicing**: 58mm / 80mm Thermal Receipt printing + client-side PDF export (`jspdf`)
- **Deployment**: Vercel (Free tier compatible)

---

## Key System Rules & Features
1. **QR & NFC Table Access**:
   - Each table has a unique route: `/t/<table_code>` (e.g. `/t/t1`, `/t/t2`).
   - The menu is unlocked **only** after entering the 4-digit numeric PIN generated by the manager.
   - Wrong table or wrong PIN displays: *"Invalid PIN. Please talk to the manager and get your PIN again."*
   - **5 wrong attempts = 5-minute database lockout** enforced via PostgreSQL RPC `verify_table_pin`.

2. **One Shared Live Table Session**:
   - All phones seated at the table see the same real-time order list.
   - Devices maintain a client `device_id` so that items ordered by that specific phone are highlighted under **"Your order"**, while orders placed by friends are listed under **"Others at your table"**.
   - No customer names or registrations asked at the table!

3. **Strict Server-Side Security**:
   - Row Level Security (RLS) is enabled on all tables.
   - Item prices are read directly from the database during order insertion (`place_table_order` RPC); clients cannot tamper with prices.
   - Supabase `service_role` key is strictly kept in server route handlers and never exposed to the client.

4. **Counter-Only Billing**:
   - No payment or checkout option is shown to customers.
   - Billing is executed strictly by the manager at the counter.
   - Manager saves customer Name + 10-digit Phone number.

5. **Customer Loyalty**:
   - Tracked automatically by phone number.
   - **Every 5 visits**, the next visit receives **1 Free Coffee** (e.g., visits 6, 11, 16, 21...).
   - The invoice highlights the customer's total visit count and eligibility for the free coffee reward.

6. **Google Sheets Sync**:
   - When a bill is finalized, data automatically syncs to your Google Sheet:
     - `Orders` tab (Invoice #, Date/Time, Table, Customer Name, Phone, Subtotal, Discount, GST, Total, Visit Count, Free Coffee Awarded)
     - `OrderItems` tab (Invoice #, Table, Item Name EN & HI, Price, Qty, Notes, Total)
     - `Customers` tab (Phone, Name, Total Visits, Free Coffees Awarded, Last Visit Date)

7. **Data Retention**:
   - Supabase retains only 30 days of closed bills (`cleanup_old_closed_bills()` function & `/api/cron/cleanup`).

8. **Manager Hub & Real-time Alerts**:
   - Single role: Manager (Google Login with email allowlist).
   - Real-time **Call Waiter** alert with synthesized Web Audio bell chime.
   - One-click **"Not available today"** toggle that syncs live to all customer devices.
   - Standee generator: view, print, and download QR codes with table number and instructions.

9. **Kitchen Display Screen (KDS)**:
   - Dedicated `/kitchen` screen for chefs with ticket columns: New (Pending) -> Cooking (Preparing) -> Ready to Serve.
   - Can be toggled ON or OFF in Manager Settings.

10. **Thermal Receipt Printing & PDF**:
    - Supports both **58mm** and **80mm** thermal receipt paper roll widths (configurable in settings).
    - One-click PDF invoice download.

## Step-by-Step Setup Guide

### 1. Supabase Database Setup
1. Log into your [Supabase Dashboard](https://supabase.com).
2. Create a new project.
3. Open the **SQL Editor** from the left navigation bar.
4. Open the file `supabase/schema.sql` from this repository, copy its entire contents, paste it into the Supabase SQL editor, and click **Run**.
5. This will create:
   - All database tables (`cafe_tables`, `table_sessions`, `categories`, `menu_items`, `orders`, `order_items`, `waiter_calls`, `customers`, `bills`, `manager_settings`, `allowed_managers`)
   - Secure server-side RPC functions (`verify_table_pin`, `generate_table_session`, `place_table_order`, `call_waiter_service`, `record_bill_and_loyalty`, `cleanup_old_closed_bills`)
   - Complete Row Level Security (RLS) policies
   - Realtime publication subscriptions
   - Default seed menu items (bilingual English + Hindi, veg/non-veg tags, meal timings) and sample tables (T1 through T6)

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local` and fill in your values:

```bash
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
MANAGER_EMAILS=owner@cafe.com,manager@cafe.com
GOOGLE_SHEET_ID=your-google-spreadsheet-id
GOOGLE_SERVICE_ACCOUNT_EMAIL=your-service-account@project.iam.gserviceaccount.com
GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

- **Supabase Keys**: Project Settings -> API (`Project URL`, `anon public` key, and `service_role secret` key).
- **Manager Allowlist**: In `MANAGER_EMAILS`, enter the comma-separated emails allowed to manage the cafe. You can also insert them into the `allowed_managers` table in Supabase.

### 3. Google Sheets API Setup (Service Account)
1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a project and enable the **Google Sheets API**.
3. Under **IAM & Admin -> Service Accounts**, click **Create Service Account**.
4. Generate a new JSON key for this service account and download it.
5. In your `.env.local`, set:
   - `GOOGLE_SERVICE_ACCOUNT_EMAIL` to the `client_email` from the JSON.
   - `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` to the `private_key` from the JSON.
6. Create a blank Google Sheet in your Google Drive (e.g., named *"Cafe POS Ledger"*).
7. Copy the spreadsheet ID from its URL:
   `https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/edit`
8. Set `GOOGLE_SHEET_ID=<SPREADSHEET_ID>`.
9. **Crucial**: Click **Share** on your Google Sheet and invite your service account email (with **Editor** permissions) so it can write rows.
10. The system automatically creates the `Orders`, `OrderItems`, and `Customers` tabs with proper headers upon the first settled bill!

### 4. Supabase Google Auth Setup (Manager Login)
1. In Supabase Dashboard, go to **Authentication -> Providers -> Google**.
2. Enable Google and input your **Google Client ID** and **Client Secret** (from Google Cloud Console -> APIs & Services -> Credentials -> OAuth 2.0 Client IDs).
3. Add `<YOUR_SUPABASE_URL>/auth/v1/callback` to your Authorized Redirect URIs in Google Cloud Console.

### 5. Running the Application
```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open `http://localhost:3000`:
- **Customer Table**: Navigate to `/t/t1` (or click on Table 1 from the home page).
- **Manager Hub**: Navigate to `/manager`. Click **Start Session** on Table 1 to generate a 4-digit PIN, then enter that PIN on the customer screen to open the menu.
- **Kitchen Display**: Navigate to `/kitchen`.
